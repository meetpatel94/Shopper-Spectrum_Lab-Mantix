# 🛒 Shopper Spectrum

Customer Segmentation and Product Recommendation System using Machine Learning.

## 📌 Project Overview
This project analyzes e-commerce transaction data to segment customers using RFM analysis and KMeans clustering. 
It also provides product recommendations using item-based collaborative filtering.

## 🧰 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- Streamlit
